# FilmCraft 0.6.0 本地开发验收

日期：2026-11-17。基于工作区原有 0.5.0 未提交改动继续开发，保留之前的源码、构建产物和验收材料。

## 完成的操作

| 功能 | 用法与结果 |
|---|---|
| 同轨拖拽 | 在视频时间线或片段列表拖动镜头；放到目标左/上半部为之前，右/下半部为之后。该轨按片段实际时长首尾相接，音频联动。保留上下移动按钮。 |
| 精确裁切 | ±1f、±5f，或输入 `12f`、`0.5s`、`00:00:01:12`；统一正数裁短、负数延长。支持非丢帧时间码，含 29.97 等非整数帧率换算。 |
| 分割 | 预览滑块按一帧步进；在片段内部点击“在此分割”，关联音频同时切开。 |
| 字幕 | 新建中文多行字幕、编辑起止及文本、点击字幕定位预览、删除、撤销。时间线上显示字幕轨。首次建立字幕轨时使用适合画幅的字号和 Windows 中文字体。 |
| 转场 | 镜头开头或结尾添加交叉溶解、淡入淡出黑场，输入帧/秒时长，更新或移除。时间线上以紫条显示。 |
| AI 操作 | MCP 新增 `filmcraft_edit_timeline`，共 27 个工具；时间线读回及修改结果包含字幕/转场。 |

## 真实引擎发现并修复的问题

`timeline.trim` 的 `delta` 为边缘移动方向：入点正数裁短，出点负数裁短。旧面板和 MCP 对裁尾同样传正数，可能仅触发引擎的素材余量钳制而没有裁短。现按用户语义换算裁尾方向，同时核对引擎返回的实际 delta；若余量不足导致实际值与要求不一致，整步回滚。

相邻片段逐条互换可能在第一步造成重叠。现在排序先计算完整位置，一次移动全部受影响片段并联动音频。选中轨已有转场时拒绝排序，提示先移除转场，避免转场残留在旧剪切位置。

## 复现

```powershell
npm run build
npm test
npm run test:real
```

如 CLI 不在默认路径，先设置 `FILMCRAFT_CLI`。仅跑新增真实剪辑检查：`npm run test:editing:real`。排障时保留该检查的素材、渲染帧与日志：`npm run test:editing:real -- --keep`。MCP 旧检查单独保留证据：`node test/mcp-smoke.mjs --real --keep`。

界面截图：`npm run preview:editing`，最终截图保存在 `docs/images/editing-0.6.0.png`。

## 验收边界与保留文件

- 没有替换当前 DSH profile 插件或重启宿主。真实宿主接口指构建产物的 HTTP handler，使用测试上下文挂载，不代表真实 DSH 宿主窗口。
- Tabbit 稳定启动器在本机不存在，未进行真实浏览器/DSH 窗口鼠标拖拽实操；拖拽请求由组件事件测试覆盖，排序执行由真实引擎覆盖。视觉检查使用仓库自带静态渲染工具。
- 拖拽仅同轨排序，不支持自由换轨或边缘拖动裁切。字幕为手动输入，尚无语音识别、SRT 导入界面。字幕按序列绝对时间保存，修改镜头后应复核。
- 已有转场的轨道要先移除转场再排序。合成短素材验证不代表所有长片或编码格式。
- 保留源码、可复用测试脚本、构建产物、实施计划、验收记录与最终截图。临时工程、生成素材、调试帧和截图过程目录在任务结束前清理；原有 0.5.0 资料保留。
