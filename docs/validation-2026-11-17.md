## 复现

在仓库根目录运行：

```powershell
npm run build
npm test
$env:FILMCRAFT_CLI = 'C:\Program Files\FilmCraft\filmcraft-cli.exe'
npm run test:real
```

真实素材自动生成在独立临时工作区中，默认结束时自动清理；要查看日志和成片：

```powershell
npm run test:real -- --keep
```

命令会打印保留目录。也可以传入至少三段自己的短视频：

```powershell
node test/mcp-smoke.mjs --real 'D:\素材\a.mp4' 'D:\素材\b.mp4' 'D:\素材\c.mp4'
```

首段应长于一秒；素材应具有音视频轨。脚本只读取源素材，所有编辑均发生在新建的临时工程中。

## 验收范围

这一版验证了独立 MCP 与面板组件的交互。没有替换当前 DSH profile 中安装的插件，也没有在真实 DSH 宿主内重新挂载；现有工作区及用户工程未改动。

时间线用于浏览和选择镜头；拖动剪辑、帧级裁切输入、字幕和转场仍是后续工作。合成短素材验证不能代表长片或全部编码格式的表现。

源码、构建产物、可复用测试脚本和最终截图保留；本次临时素材、测试工作区和截图过程文件在交付前清理。
