# 剪辑功能实施计划

目标：在现有侧栏中完成同轨拖拽排序、帧级裁切、手动字幕和常用视频转场，所有编辑可撤销，失败整步回滚。

1. 核实 FilmCraft CLI 0.7.2 命令与返回结构。已确认字幕轨、字幕文本/时间、视频转场及逐帧裁切接口存在。
2. 实现同轨拖拽插入排序，保留上下移动按钮；按真实时长重新排列，并保持关联音频同步。增加逐帧步进、秒/帧/时间码输入、播放头分割。
3. 实现字幕新增、修改、删除及时间定位；新增交叉溶解、淡入淡出黑场，支持修改时长和移除，时间线上显示字幕和转场。
4. 通过面板交互测试、宿主接口测试、真实素材渲染/导出检查及 344px 界面截图验收。保留源码、测试和最终截图，清理本次临时素材与过程文件。

边界：本轮拖拽指同轨镜头排序，不包含自由换轨或拖动边缘裁切。字幕为手动输入，不包含语音识别。字幕时间以序列为准，修改镜头顺序后须复核字幕。安装进真实 DSH 宿主不在本轮范围内。

实施结果：四项功能已完成；真实引擎 81 项检查通过。深浅色窄侧栏渲染已检查。真实 DSH 窗口中的鼠标拖拽尚未实操验收，原因是本机缺少 Tabbit 启动器；组件拖拽事件与真实宿主排序接口已分别验证。完整证据与复现步骤见 [验收记录](validation-0.6.0.md)。
